# My FANZA Bookshelf

FANZAの購入済み作品を、自分専用のローカル本棚として整理するための静的Webアプリです。FANZA公式サイトの購入一覧が見づらい場合に、画面上に表示されている作品メタ情報をJSONで取り込み、検索、タグ、お気に入りで管理できます。

## 重要な前提

- このツールはFANZA公式とは無関係の個人用ツールです。
- 公開サービスではなく、自分専用・手動管理用として使う想定です。
- 自動巡回、大量アクセス、次ページの自動取得はしません。
- DRM回避、動画保存、画像保存、課金コンテンツの取得はしません。
- userscriptが読むのは、ログイン済みブラウザでユーザーが開いている購入一覧ページのDOMだけです。
- 取得対象はタイトル、URL、サムネURL、購入日、ジャンル/タグらしき表示、作品IDなど、画面上に表示されているメタ情報に限ります。

## できること

- JSONインポート
- JSONエクスポート
- タイトル、メーカー、タグ、メモの検索
- お気に入り管理
- タグ/ジャンル絞り込み
- 購入日、タイトル、更新日、お気に入り優先のソート
- カード上でのお気に入り編集
- localStorageへの自動保存
- サムネイル非表示モード

## できないこと

- FANZAへのログイン代行
- 購入一覧の自動巡回
- 次ページの自動取得
- 作品本体、動画、画像ファイルの保存
- DRMや視聴制限の回避
- 複数端末間の自動同期

## GitHub Pagesで公開する方法

1. この `fanza-bookshelf` ディレクトリをGitHubリポジトリに置きます。
2. GitHubのリポジトリ設定から **Settings > Pages** を開きます。
3. Sourceに公開したいブランチを選びます。
4. `fanza-bookshelf` をリポジトリ直下に置いた場合は、公開URLの末尾に `/fanza-bookshelf/` を付けてアクセスします。
5. ビルドは不要です。`index.html` がそのまま動作します。

ローカルで確認するだけなら、`index.html` をブラウザで直接開いても動きます。

## Tampermonkeyへのuserscript導入方法

1. Tampermonkeyをブラウザにインストールします。
2. Tampermonkeyのダッシュボードを開きます。
3. 新規スクリプトを作成します。
4. `userscript/fanza_purchase_exporter.user.js` の内容を貼り付けて保存します。
5. FANZAの購入一覧ページを開くと、右下に「本棚JSON出力」ボタンが表示されます。

Tampermonkeyにはスクリプトのインポート/エクスポート機能もあります。必要に応じてTampermonkey公式ドキュメントを確認してください。

## FANZA購入一覧からJSONを出力する方法

1. FANZAにログインします。
2. 購入一覧ページを手動で開きます。
3. 右下の「本棚JSON出力」ボタンを押します。
4. モーダルに、現在表示されているページ内の作品メタ情報がJSONで表示されます。
5. 「コピー」または「JSONダウンロード」を使って保存します。

userscriptは現在開いているページのDOMだけを読みます。別ページの作品を取り込みたい場合は、ユーザー自身がそのページを開いてから同じ操作をしてください。

## 本棚アプリへJSONをインポートする方法

1. `index.html` を開きます。
2. 「JSONインポート」を押します。
3. userscriptでダウンロードしたJSON、または `sample-data.json` を選択します。
4. 作品カードが本棚に追加されます。

同じ `id` または `url` の作品は重複追加されません。既存作品のメモ、お気に入りなどは保持されます。新しいJSONにしかないタイトル、サムネURL、購入日、タグなどは可能な範囲で補完されます。

## データ保存とバックアップ

本棚データはブラウザの `localStorage` に保存されます。ページを閉じても同じブラウザでは状態が残りますが、ブラウザ設定の削除、別端末利用、プライベートブラウズなどでは失われる場合があります。

バックアップのため、定期的に「JSONエクスポート」を実行してください。エクスポートファイル名は `fanza-bookshelf-YYYY-MM-DD.json` です。

## サンプルデータ

動作確認用に `sample-data.json` を用意しています。実在作品名ではないダミーデータです。
